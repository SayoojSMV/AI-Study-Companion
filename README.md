# 📚 AI Study Companion

**AI Study Companion** is a feature-rich, modern web application built to streamline and supercharge the modern learning experience. Leveraging advanced AI capabilities, it acts as a personalized tutor, resource manager, and productivity hub for students and developers alike.

## ✨ Key Features

- **Intelligent Q&A & Assistance:** Interactive AI-driven support powered by the Gemini API to help break down complex topics and answer technical questions.
- **Modern Tech Stack:** Built with a blazing-fast React and Vite frontend, backed by a robust Node.js/Express server.
- **Secure Authentication & Data:** Integrated with Firebase for reliable user state management and Firestore database handling.
- **Clean & Responsive UI:** Designed with seamless accessibility and productivity workflows in mind.

## 🛠️ Tech Stack

- **Frontend:** React, Vite, TypeScript
- **Backend:** Node.js, Express, TypeScript (`tsx`)
- **Database & Auth:** Firebase (Firestore)
- **AI Integration:** Google Gen AI SDK (`@google/genai`)
